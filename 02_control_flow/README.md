# Control Flow

This module demonstrates how Python controls the execution of a program.

## Topics Covered

- `if`
- `elif`
- `else`
- `for` loops
- `while` loops
- `range()`
- `break`
- `continue`
- `pass`
- Nested conditions

## Python Syntax

```python
if condition:
    statement
elif another_condition:
    statement
else:
